# 데모 시나리오 (3분, 초안)

> 인물·의원은 가상이다. 시드 데이터와 일치시킨다.

**페르소나 (가정)**: 도쿄의 29세 직장인. 기미가 고민이고, 3박 4일 서울 여행 중 피부과 시술을 받고 싶다. 현지에서 견적이 바뀔까 봐 불안하다.

| # | 장면 | 화면 | 보여줄 포인트 |

| 1 | 일본어로 문진 — 고민 "기미", 여행 일정 입력, 금기 항목 체크 | 환자 `/intake` | 금기 스크리닝 |

| 3 | 의원 콘솔에 신규 진료 요청 도착, 사진·문진 확인 | 의원 `/clinic/consult/[id]` | 의사가 사전 자료를 보고 들어감 |
