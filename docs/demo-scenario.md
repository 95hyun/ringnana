# 데모 시나리오 (3분, flow-v2)

> 인물·의원은 가상이다. 시드 데이터와 일치시킨다. 흐름 정본: [product/user-flow.md](product/user-flow.md).

**페르소나 (가정)**: 도쿄의 29세 직장인. 기미가 고민이고, 3박 4일 서울 여행 중 피부과 시술을 받고 싶다. 현지에서 견적이 바뀔까 봐 불안하다.

| # | 장면 | 화면 | 보여줄 포인트 |
|---|---|---|---|
| 1 | 로그인 → 의사 찾기: 고민 "シミ"·일본어 상담·여행 전 날짜로 필터 | 환자 `/jp/doctors` | 목적에 맞는 의사를 내가 고른다 (후기·랭킹 없음) |
| 2 | 의사 프로필 → 상담 시간 선택 | `/jp/doctors/[id]` | 의원·언어·빈 시간이 한눈에 |
| 3 | 문진(금기 스크리닝) + 동의 → 신청 완료 → 내 예약 "医師確認中" | `/jp/consult/[id]/intake` → `requested` → `/jp/reservations` | 의사가 보기 전에 정보가 정리된다 |
| 4 | (화면 전환) 의원 콘솔에 신청 도착 → 문진·사진 검토(S2) → **수락** | 의원 `/ko/clinic/consult/[id]` | 의사 판단이 주인공 |
| 5 | 환자 내 예약 "予約確定" → 의사가 진료 시작 → 입장 → 화상 상담(자막) | `/jp/consult/[id]` → video | 팀원 파트 |
| 6 | 진료 완료 → 의사 노트·확정 견적(₩ + 約¥) → 체류 일정 | `/jp/consult/[id]/done` → `/jp/quote/[id]` → `/trip` | 가격 투명성, 일정 맞춤 |
| 7 | (시간 점프) 귀국 후 D+14 체크인 → 의원에 이상 보고 | `/jp/aftercare`, 의원 `/ko/clinic/aftercare` | 사후관리 공백 해소 |

- 시연 시각과 예약 시각이 어긋나도 되도록, 입장은 의사의 "진료 시작"으로 연다.
- 가격 표기: 피치에서는 USD로 말한다. 화면은 확정가 KRW + 참고 환산 約¥.
- 시연 직전 데이터 초기화: 배포 DB 시드 재실행([deploy.md](deploy.md)).
