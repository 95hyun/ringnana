# Ringnana

일본인 방한객이 **방한 전 화상으로 한국 피부과 의사에게 진단·시술 계획·확정 견적**을 받고, 방한 일정에 맞춰 시술한 뒤, **귀국 후에도 화상으로 사후관리**를 받는 플랫폼.

> 해커톤 프로젝트. 외국인 환자 비대면 진료는 의료해외진출법 개정으로 2027년 5월 시행 예정이다.

## 구조
```
ringnana/
├── apps/
│   ├── web/        # 플랫폼: 환자 앱(일본어) + 의원 콘솔 — Next.js
│   └── video/      # 화상통화 (팀원 담당)
├── supabase/
│   └── migrations/ # DB 스키마
└── docs/           # 기획·설계·연동 계약 (Claude가 읽는 문서)
```
