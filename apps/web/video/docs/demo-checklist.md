# 시연 점검표 (Chrome)

> 사람 확인이 최종 근거다. 실패한 항목은 [README](../README.md) "현장 조정"과 [docs/video.md](../../../../docs/video.md)를 본다.

## 0. 사전 확인
- [ ] 플랫폼 H1이 `photos.consented_at`과 `consultations` 번역 칸 3개를 적용했다 (적용 전이면 사진 제출·소견 번역 저장이 실패한다)
- [ ] 환경변수가 채워져 있다 (로컬 `apps/web/.env.local` 또는 Vercel 설정: Supabase 3개, `ANTHROPIC_API_KEY`, 선택 `ALLOWED_DEV_ORIGINS`·TURN 3개)
- [ ] 양쪽 이어폰 착용

## 1. 입장·연결
- [ ] 배포본 또는 로컬(`pnpm dev:https` → 다른 노트북에서 `https://{IP}:3000`, 인증서 허용) 접속, 카메라·마이크 허용
- [ ] 의원 콘솔·환자 화면에서 입장 → 1:1 영상·음성 연결, 입장 상태 표시가 바뀜
- [ ] 없는 진료 주소로 들어가면 "진료를 찾을 수 없습니다"
- [ ] 의사 탭을 하나 더 열기 → 먼저 연 탭이 "다른 창에서 입장했습니다"로 멈추고 새 탭으로 연결

## 2. 통역
- [ ] 의사 한국어 → 환자 화면 일본어 자막 + 일본어 음성, 원문 함께 표시, `AI翻訳` 표시
- [ ] 환자 일본어 → 의사 화면 한국어 자막 + 한국어 음성
- [ ] 번역 음성이 나오는 동안 상대 원음이 작아지고, 번역이 되돌아가지 않음
- [ ] [음성] 끄면 자막만 표시, [통역] 끄면 내 말이 전달되지 않음
- [ ] 숫자 문장 번역 확인: "레이저 토닝 5회, 2주 간격"
- [ ] 번역 키를 빼면 원문 + "번역하지 못했습니다"로 표시되고 통화는 계속됨

## 3. 화면 언어
- [ ] 환자 화면 일본어 → 한국어 → 일본어 전환, 새로고침해도 유지
- [ ] 다른 진료방으로 들어가면 다시 `lang`(기본 일본어)으로 시작
- [ ] 화면을 한국어로 바꿔도 환자 통역 언어는 일본어 그대로

## 4. 촬영
- [ ] [얼굴 촬영 요청] → 환자 화면 배치 전환 + 동의 체크 → 「正面を向いてください」
- [ ] 환자가 **자기 왼쪽**으로 고개를 돌리면 좌측 단계가 진행된다 (반대면 `YAW_SIGN` 수정)
- [ ] 위를 보면 상하 각도가 위로 판정된다 (반대면 `PITCH_SIGN` 수정)
- [ ] 화살표 ◀/▶가 거울 화면에서 고개를 돌리는 방향과 맞다
- [ ] 정면·좌·우 자동 촬영, 촬영마다 번쩍임·셔터음, 의사 화면 "촬영 중 n/3" 증가
- [ ] 미리보기에서 1장 [撮り直す] → 그 방향만 재촬영 → [提出する] → 의사 화면에 3장 표시
- [ ] **저장된 좌측 사진이 실제 환자의 왼쪽 얼굴**이다 (의원 콘솔에서 확인)
- [ ] 인터넷을 끊고 제출 → 사진 유지 + [もう一度提出] → 다시 연결 후 제출 → 기록이 1개만 생김
- [ ] 촬영 도중 의사 재요청 → 동의부터 다시, 이전 사진 섞이지 않음
- [ ] 의사 [촬영 취소] → 환자 화면 통화 배치로 복귀
- [ ] 15초 미인식 → [手動で撮影] 동작
- [ ] 어두운 곳 → 「もう少し明るい場所に移動してください」 안내만 나오고 촬영은 막히지 않음
- [ ] `?role=patient&test=1` → [撮影テスト]로 통화 없이 촬영·제출

## 5. 종료
- [ ] 의사 [통화 종료] → 의사는 의원 콘솔, 환자는 견적 화면으로 함께 이동
- [ ] 환자가 제출 중일 때 의사가 종료 → 제출이 끝난 뒤 환자 이동
- [ ] 의원 콘솔에서 통화 중 사진(회차별) 확인

## 6. 소견 번역 (플랫폼 요청 반영 후)
- [ ] 의원 콘솔에서 소견 저장 → 환자 견적 화면에 일본어 번역 + 「自動翻訳」 + [原文を見る]
- [ ] 소견 수정 직후 예전 번역이 보이지 않고 「翻訳を準備中です」 → 번역 완료 후 새 번역
- [ ] 번역 실패 시 콘솔에 [다시 번역]

## 7. 점검 화면 (선택)
- [ ] `/check` → 카메라 미리보기, 마이크 레벨, 테스트음, [戻る]

## 8. 한 대 시연 (PC 1대, Chrome 창 2개를 나란히)
- [ ] 의사·환자 주소를 각각 새 창으로 열기 → 양쪽 위에 "시연 모드"/「デモモード」
- [ ] 상대 원음이 들리지 않고, 영상·자막·번역 음성은 나옴
- [ ] 환자 창 [話す] → 일본어 한 문장 → 의사 창에 한국어 자막·음성, 환자 창 버튼이 원래대로 돌아옴
- [ ] 한 창이 듣는 동안 다른 창 [말하기]가 꺼지고 "다른 창이 듣는 중입니다" 표시
- [ ] 예시 문장 버튼(환자 일본어·의사 한국어) → 상대 창에 번역 자막·음성
- [ ] 환자 창을 닫으면 의사 창의 "시연 모드" 표시가 사라지고 연속 인식으로 돌아감
- [ ] 한 창만 `&demo=1`로 열면 상대 창 없이도 시연 모드
- [ ] 같은 웹캠으로 촬영 요청 → 환자 창에서 정면·좌·우 촬영·제출 → 의사 창에 3장
